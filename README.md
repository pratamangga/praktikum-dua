# Sistem Rekomendasi Jurusan
Praktikum 2 Sistem Cerdas menggunakan Streamlit

## Fakta yang dapat dimasukkan kedalam Sistem :

1. Mahasiswa memiliki minat pada bidangnya.
2. Mahasiswa memiliki kemampuan akademiknya.
3. Mahasiswa dapat memilih Saintek/Soshum.
4. Nilai dapat mempengaruhi pilihan jurusannya.
5. Hobi dapat menjadi pertimbangan tambahan.
